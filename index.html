O que eu faço

Três tipos de problema que eu resolvo

  1. 01

    Automação e RPA

    Se alguém passa o dia copiando dados de um sistema para outro, preenchendo o mesmo formulário ou baixando relatórios, isso pode virar um robô. Eu mapeio o processo com quem faz o trabalho, automatizo e deixo rodando com agendamento, log e relatório.

    Python · Selenium · Playwright · Pandas · ETL

  2. 02

    APIs e integrações

    Faço sistemas que não conversam passarem a conversar: APIs REST, webhooks, filas de mensagem e funções serverless. Quando um serviço externo é lento, o pedido vai para segundo plano e o usuário não fica esperando.

    Node.js · TypeScript · FastAPI · AWS Lambda · API Gateway · RabbitMQ

  3. 03

    Aplicações web

    Telas e módulos de sistemas internos, do front ao banco: formulários, listagens, filtros e regras de negócio, ligados a um backend próprio.

    Angular · TypeScript · PostgreSQL · MySQL · MongoDB

Como eu trabalho

O que vem junto com o código

Testo antes de gravar
Robôs e integrações rodam primeiro em simulação. Só escrevem em produção depois que o resultado foi conferido.
Conto com o erro
Retentativa, timeout e registro da falha fazem parte da entrega. Quando algo quebra, dá para saber onde e por quê.
Escrevo para quem vem depois
Documentação em linguagem simples, dizendo o que o sistema faz e o que ainda não faz.
Converso com quem usa
Vim do suporte técnico. Antes de escrever código, procuro entender a rotina de quem vai usar.
